# Dog-Adoption-Website-fixed-
# An informative website built from scratch (no AI) about an adoption center for animals. This website aims to introduce the fundamentals of HTML, CSS and JavaScript to real life problems. On this website, the user can do the following actions:
# 1. Explore different animals and explore their info page.
# 2. Use the search bar to search for the desire animal.
# 3. Submit a form with information about the user when they want to adopt an animal.
